# Учебные игры на Rust и Macroquad

Репозиторий ведёт последовательность небольших учебных игр на Rust, Cargo и Macroquad. Цель не в том,
чтобы получить конкретную игру любой ценой, а в том, чтобы на простых проектах разобрать фундамент, на
котором стоит любая игра: game loop, delta time, ввод, позицию и скорость, столкновения, состояние
игры, коллекции игровых объектов, уровни, счёт и рендеринг.

Каждая игра — самостоятельный крейт workspace: она читается целиком в своём каталоге, не зависит от
остальных и не выделяет с ними общий код. Повторение похожих сущностей в разных играх — осознанная
цена того, что каждую из них можно прочитать от начала до конца.

## Запуск

Репозиторий — одно приложение с общим меню: одна команда открывает окно со списком игр, а выбранная
игра запускается в том же окне и возвращает в меню, не закрывая программу.

```text
cargo run
```

Каждую игру можно запустить и в обход меню, отдельным процессом, — так удобнее при разработке самой
игры:

```text
cargo run -p pong
cargo run -p arkanoid
cargo run -p asteroids
cargo run -p shooter
cargo run -p room
```
