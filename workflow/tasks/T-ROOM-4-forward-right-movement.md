# T-ROOM-4: Горизонтальные forward/right и движение по полу

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-4` — ID задачи из backlog, которую закрывает эта карточка.

## Цель

Клавиши `W`/`A`/`S`/`D` двигают игрока по полу относительно направления взгляда, со скоростью, не
зависящей от FPS, и без ускорения по диагонали.

## Scope

- Одна именованная функция перехода «yaw → горизонтальное направление» (`forward`, `right`), pitch в
  неё не входит (D-48).
- `Input` — структура одного кадра (нажатые клавиши движения + смещение мыши, D-44/D-35).
- Вектор намерения из нажатых клавиш, нормализован (кроме нулевого вектора), × скорость × delta time.

## Out Of Scope

- Вертикальная ось (падение/прыжок — `T-ROOM-5`/`T-ROOM-6`).
- Столкновения (`T-ROOM-7`/`T-ROOM-8`) — сквозь стены на этой позиции ожидаемо проходит.
- Sprint/crouch (D-46).

## Критерии приёмки

- [ ] `forward` при yaw=0 совпадает с ожидаемой мировой осью, `right` перпендикулярен.
- [ ] `forward`/`right` единичной длины при любом yaw, вертикальная компонента = 0.
- [ ] поворот на 90° переставляет `forward` на место прежнего `right` (или наоборот, знак фиксирует тест).
- [ ] путь за секунду одинаков при 60 и 120 fps.
- [ ] диагональ не быстрее прямого движения.
- [ ] противоположные клавиши вместе — игрок на месте, без NaN.
- [ ] `make check` зелёный.

## Риски

- Перепутанная ось `right` относительно `forward` — ловится тестом на поворот 90°.
