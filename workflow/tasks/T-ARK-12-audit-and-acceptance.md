# T-ARK-12: Аудит и приёмка первой версии Arkanoid

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ARK-12` — позиция 1 backlog: аудит покрытия по D-18, аудит простоты, полный набор проверок
  качества и подготовка чек-листа приёмки владельцем.

## Цель

Подтвердить, что первая версия Arkanoid соответствует принятой идее, а покрытие unit-тестами
соответствует D-18 (двенадцать пунктов), и подготовить владельцу пошаговый чек-лист наблюдаемой
приёмки, включая развилку по пункту 13 (`GameWon`).

## Scope

- Аудит покрытия по двенадцати пунктам D-18 поимённо: тест на каждый пункт. Недостающее — дописать по
  TDD; отсутствие пробела фиксируется как результат аудита.
- Отдельная перепроверка мест из `T-ARK-7` и `T-ARK-9`, где восемь тестов позеленели с первого запуска
  (код попал в скелет/интеграцию раньше теста) — с прицелом на то, что тест мог проверить поведение
  кода, а не требование плана.
- Аудит простоты: запреты D-02 (включая дополнение об отсутствии общего между играми), требования D-07,
  сущности D-17, границы D-21, отсутствие внешних assets.
- Полный набор проверок качества D-06 (`make check`) по workspace.
- Проверка независимости скорости от FPS на уровне логики (существующие тесты эквивалентности шагов).
- Чек-лист приёмки владельца — тринадцать пунктов плана превращены в наблюдаемую последовательность
  действий, с явной развилкой по пункту 13 (`GameWon`: пройти игру целиком либо принять по unit-тесту
  `T-ARK-8` + наблюдение последнего уровня).

## Out Of Scope

Новые игровые возможности, рефакторинг ради красоты, любые расширения из D-21, начало Game 03 —
Asteroids, крейт `pong`, `workflow/roadmap.md`, `workflow/backlog.md` (до подтверждения владельца).

## Критерии приёмки

- [x] Все 12 пунктов D-18 закрыты поимённо тестами; пробелов не найдено (см. отчёт ниже).
- [x] Места T-ARK-7 / T-ARK-9 перепроверены отдельно, результат зафиксирован; найдена одна
      двусмысленность (движение ракетки в `GameOver`/`GameWon`), закрыта тестом
      `terminal_states_still_move_the_paddle`.
- [x] Аудит простоты пройден без находок нарушений D-02/D-07/D-17/D-21.
- [x] `make check` зелёный (D-06 целиком).
- [x] Чек-лист приёмки владельца готов, с развилкой по `GameWon` (см. финальный отчёт сессии).
- [ ] Задача НЕ закрывается до ответа владельца на специальный gate (порядок завершения особый) —
      сессия остановлена намеренно, checkpoint не создан.

## Риски

- Ложное впечатление покрытия, если тест написан после кода и проверяет фактическое поведение, а не
  требование плана — отдельно перепроверяются места T-ARK-7/T-ARK-9.
- Пропуск незамеченного нарушения D-02 (случайно всплывший общий тип/модуль между играми) — проверяется
  grep'ом по обоим крейтам.
