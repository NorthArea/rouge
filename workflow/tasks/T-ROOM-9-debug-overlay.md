# T-ROOM-9: Debug overlay

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-9` — ID задачи из backlog.

## Цель

Поверх сцены видны позиция игрока, yaw и pitch — так, чтобы по ним можно было изучать координаты и
трансформации.

## Scope

- Возврат из 3D-режима в экранный на время отрисовки текста; три строки в углу: позиция (x, y, z),
  yaw и pitch в градусах.
- Числа форматируются с 1-2 знаками после запятой.

## Out Of Scope

- FPS, счётчики кадров, графики, переключение overlay по клавише, внутриигровое меню (D-46/D-47).

## Критерии приёмки

- [ ] перевод радиан в градусы и формат строки — тестируется, если вынесены в функцию; иначе решение
      «тест избыточен» называется в отчёте явно.
- [ ] `make check` зелёный.

## Проверка

```text
Если функция форматирования выделена — тест вместе с реализацией, закрытие изолирующей мутацией.
Если не выделена — явно назвать в отчёте, почему (D-03: абстракция ради тестируемости запрещена).
TARGETED: make check
FULL: make check
SPECIAL: gate не назначен позиции.
```

## Риски

- Нет существенных: отрисовка не тестируется (D-10).
