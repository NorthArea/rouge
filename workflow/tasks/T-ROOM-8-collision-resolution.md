# T-ROOM-8: Разрешение столкновений по осям и скольжение вдоль стены

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-8` — ID задачи из backlog.

## Цель

Игрок не проходит сквозь стены и кубы, а упёршись в стену под углом, продолжает двигаться вдоль неё.

## Scope

- Перемещение за кадр применяется по одной оси за раз: смещение по оси → проверка `Aabb` игрока со
  всеми `Aabb` комнаты → при пересечении смещение по этой оси отменяется → следующая ось.
- Три оси обрабатываются одинаково; вертикальная ось дополнительно: столкновение сверху вниз
  обнуляет `velocity_y` и поднимает `on_ground`.
- Скольжение — прямое следствие пооосевого разрешения, не отдельная функция.

## Out Of Scope

- Выталкивание из уже случившегося глубокого пересечения; непрерывное обнаружение столкновений;
  наклонные поверхности (D-46).

## Критерии приёмки

- [ ] идущий прямо в стену останавливается перед ней, не оказывается за ней.
- [ ] идущий в стену под углом теряет составляющую поперёк стены, сохраняет вдоль (обе горизонтальные оси).
- [ ] идущий мимо куба огибает его скольжением; идущий в него — останавливается.
- [ ] не проходит ни через одну из четырёх стен.
- [ ] падение на верхнюю грань куба останавливает падение, обнуляет `velocity_y`, поднимает `on_ground`.
- [ ] прыжок под нижнюю грань препятствия гасит подъём, не проносит сквозь.
- [ ] `make check` зелёный.

## Проверка

```text
Тесты вместе с реализацией (прецедент предыдущих позиций), закрытие изолирующими мутациями, sha256 сверяется.
TARGETED: make check
FULL: make check
SPECIAL: gate не назначен позиции.
```

## Риски

- Отмена всего перемещения вместо одной оси — ловушка «прилипания» к стене на диагонали; ловится тестом на угол к стене.
- Перепутанная ось — проход сквозь стену; ловится тестом на каждую стену отдельно.
