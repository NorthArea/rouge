# T-ROOM-11: room/README.md

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-11` — ID задачи из backlog.

## Цель

README объясняет человеку, который пишет свою первую трёхмерную сцену, что именно делает эта игра и
какие понятия в ней изучаются.

## Scope

`room/README.md` по пунктам задания, каждое понятие с опорой на конкретное место в коде: `Vec3` и
третья ось; мировые оси комнаты; local/world coordinates (forward из yaw); transform; yaw/pitch и
ограничение pitch; перспективная камера и FOV; гравитация; collider (AABB) и разрешение столкновений
по осям. Отдельный раздел — чем Room отличается от предыдущих игр: ни счёта, ни состояний; физика
написана руками, не взята из движка (D-43), и где граница между арифметикой и physics engine.
