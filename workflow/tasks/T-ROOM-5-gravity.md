# T-ROOM-5: Гравитация, падение и признак «на земле»

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-5` — ID задачи из backlog.

## Цель

Игрок, оказавшийся выше пола, падает с ускорением и останавливается на уровне пола; код знает, стоит
игрок на земле или находится в воздухе.

## Scope

- Вертикальная скорость — поле игрока.
- Обновление: `velocity_y -= gravity * delta_time`, `position.y += velocity_y * delta_time`.
- Приземление: позиция ниже уровня пола (+ высота глаз) поднимается до него, `velocity_y = 0`,
  признак «на земле» истинен; ложен, как только игрок выше пола.
- Порядок операций фиксирован: скорость → позиция → приземление.

## Out Of Scope

- Прыжок (`T-ROOM-6`).
- Столкновения с вертикальными поверхностями (`T-ROOM-8`).
- Наклонные поверхности/лестницы (D-46).

## Критерии приёмки

- [ ] поднятый над полом игрок опускается за кадр, скорость становится отрицательнее.
- [ ] за два кадра подряд падение больше вдвое первого.
- [ ] падение останавливается ровно на уровне пола, не ниже.
- [ ] на полу скорость обнулена, on_ground истинен; в воздухе — ложен.
- [ ] стоящий на полу без ввода не проваливается и не дрожит.
- [ ] `make check` зелёный.

## Риски

- Неверный порядок скорость/позиция/приземление — визуальное дрожание; ловится тестом «нет дрожания».
