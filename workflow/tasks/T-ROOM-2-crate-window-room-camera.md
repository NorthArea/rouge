# T-ROOM-2: Крейт room, окно и перспективная камера

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-2` — ID задачи из backlog, которую закрывает эта карточка.

## Цель

`cargo run -p room` открывает окно, в котором перспективная камера смотрит на комнату — пол, четыре
стены и несколько кубов-препятствий, — в коде явно видны стадии кадра, `Esc` выходит.

## Scope

- Новый крейт `room` шестым участником workspace (`members` в корневом `Cargo.toml`).
- `room/Cargo.toml` с зависимостью `macroquad = "0.4.16"`.
- `room/src/lib.rs` с единственным публичным элементом `pub async fn run()` и приватными модулями.
- `room/src/main.rs` с `window_conf` и `#[macroquad::main]`, вызывающий `room::run().await`.
- Стадии кадра D-09 как видимая структура кода: ввод → delta time → обновление → столкновения →
  рендеринг → следующий кадр.
- Геометрия комнаты — константы этого крейта; отрисовка примитивами Macroquad из режима `Camera3D`.
- Камера фиксирована в точке комнаты и смотрит в её центр (игрока ещё нет).
- Перспектива и FOV — комментарий объясняет проекцию.

## Out Of Scope

- Игрок, взгляд, движение, гравитация, прыжок, столкновения, overlay.
- Пункт меню и правка `menu/Cargo.toml` (`T-ROOM-10`).
- README (`T-ROOM-11`).
- Освещение, текстуры, модели и любые внешние assets (D-46).

## Критерии приёмки

- [ ] `cargo run -p room` открывает окно с полом, четырьмя стенами и кубами, перспектива не искажена.
- [ ] `Esc` выходит.
