# T-ROOM-3: Взгляд — yaw, pitch и камера от первого лица

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-3` — ID задачи из backlog, которую закрывает эта карточка.

## Цель

Мышь вращает взгляд: горизонтальное движение меняет yaw, вертикальное — pitch; pitch ограничен так,
что камера не переворачивается; курсор захвачен; камера стоит в позиции игрока и смотрит туда, куда
смотрит взгляд.

## Scope

- `Player` — данные: `position: Vec3`, `yaw: f32`, `pitch: f32` (D-44). Неподвижен на этой позиции.
- Смещение мыши за кадр × чувствительность → прибавка к yaw и pitch.
- Одна именованная функция ограничения pitch (~±89°, вертикаль исключена намеренно).
- Направление взгляда из yaw/pitch — единая точка (используется камерой как `target`).
- Захват курсора и скрытие указателя при входе, снятие при выходе по `Esc` (не тестируется, D-10).
- `Input` — структура одного кадра (смещение мыши), по прецеденту D-35/D-44.

## Out Of Scope

- Движение по клавишам (`T-ROOM-4`), гравитация, прыжок, столкновения.
- Head bob, camera shake, настройка чувствительности в интерфейсе (D-46).

## Критерии приёмки

- [ ] pitch выше предела зажимается пределом; ниже — нижним пределом; внутри — не меняется.
- [ ] yaw накапливается предсказуемо от последовательных смещений мыши (приведение к диапазону — решение исполнителя, зафиксировано тестом).
- [ ] направление взгляда при yaw=0, pitch=0 совпадает с ожидаемой мировой осью.
- [ ] `make check` зелёный.

## Проверка

Записать RED до изменения рабочего кода и по одной строке на каждый новый тест с фактической ошибкой.

```text
RED: make test-target TEST=<имя>
GREEN: make test-target TEST=<имя>
TARGETED: make check
FULL: make check
SPECIAL: gate не назначен позиции (mouse look подтверждается чек-листом T-ROOM-12).
```

## Риски

- Перепутанный знак/порядок тригонометрии в переходе yaw/pitch → направление — ловится тестом на
  нулевые углы.
