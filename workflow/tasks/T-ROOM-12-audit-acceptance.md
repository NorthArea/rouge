# T-ROOM-12: Аудит и приёмка первой версии Game 05

## Статус

Главный статус, выбор задачи и состояние восстановления находятся в `workflow/progress.md`. Эта карточка
нужна для работы над одной задачей и удаляется после статуса `DONE`.

## Реализует

- `T-ROOM-12` — ID задачи из backlog.

## Цель

Подтвердить, что первая версия соответствует заданию, а покрытие тестами — обязательному списку D-45.

## Scope

- Аудит покрытия по семи пунктам D-45 поимённо.
- Аудит простоты: D-02, D-07, D-44, D-46, D-43 (нет physics engine под другим именем), D-48 (одна
  точка перехода yaw → направление), нет `use pong`/`use arkanoid`/`use asteroids`/`use shooter`,
  нет общего модуля, зависимости — только `macroquad`.
- Полный набор проверок D-06 по workspace.
- Наблюдаемый прогон по чек-листу — специальный gate, пропущен по решению управляющего.

## Out Of Scope

- Новые игровые возможности, расширения D-46, рефакторинг ради красоты, переписывание предыдущих игр.
- Game 06 в очередь не заводится.

## Критерии приёмки

- [ ] все 7 пунктов D-45 названы поимённо с закрывающим тестом.
- [ ] аудит простоты без замечаний или с явно названными и обоснованными отклонениями.
- [ ] `make check` зелёный.

## Проверка

```text
TARGETED: make check
FULL: make check
SPECIAL: наблюдаемый прогон по чек-листу приёмки (19 пунктов) пропущен по решению управляющего
2026-09-25 (default authority, прецедент Asteroids/Game 04); отложен до конца очереди Game 05.
Пункты, требующие экрана, перечисляются в отчёте.
```

## Риски

- Отклонения от буквального задания, если есть, — называются явно, а не скрываются.
