# Идея: 3D Room

Файл: `workflow/source/2026-08-15-3d-room.md` — дата создания идёт в имя, по ней виден возраст идеи.

## Статус

`на решении у управляющего` — требований достаточно для реализации первой версии.

## Цель

Реализовать на Rust первую минимальную 3D-сцену как переход от 2D к 3D.

Пользователь должен уметь ходить по небольшой комнате от первого лица, смотреть мышью, прыгать и сталкиваться со стенами. Учебная цель — понять `Vector3`, transform, local/world coordinates, perspective camera, FOV, gravity и базовые 3D-коллизии.

## Ограничения

- Язык: Rust.
- Сборка: Cargo.
- Игровой движок: Fyrox.
- Не добавлять врагов, оружие и combat.
- Не создавать собственный renderer или physics engine.
- Использовать встроенную 3D-физику Fyrox только для базового движения и столкновений.
- Геометрия уровня простая: пол, стены, несколько кубов/препятствий.
- Внешние assets высокого качества не требуются.
- Проверки: `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test`, `cargo build`.

## Основной сценарий

1. Игрок запускает приложение и появляется внутри простой 3D-комнаты.
2. WASD перемещает персонажа.
3. Движение мыши вращает камеру по yaw/pitch.
4. Игрок может прыгнуть; гравитация возвращает его на пол.
5. Игрок не проходит сквозь стены и препятствия.
6. Игрок осматривает комнату и на практике видит разницу между локальными и мировыми направлениями.

## Этапы реализации

1. **Первая 3D-сцена**

   - Создать сцену с полом, четырьмя стенами и несколькими объектами.
   - Добавить perspective camera.
   - Сцена визуально читается без сложных assets.

2. **Player controller**

   - Создать игрока с collider/rigid body подходящего типа.
   - WASD двигает игрока по поверхности.
   - Скорость движения не зависит от FPS.

3. **Mouse look**

   - Горизонтальное движение мыши изменяет yaw, вертикальное — pitch.
   - Pitch ограничен, чтобы камера не переворачивалась.
   - Курсор захватывается во время игры.

4. **Local и world coordinates**

   - Направление движения вперёд рассчитывается относительно ориентации игрока/камеры.
   - В README объяснить, почему «вперёд игрока» не равно постоянной мировой оси.

5. **Гравитация и прыжок**

   - Персонаж падает на пол.
   - Прыжок работает только при нахождении на земле.
   - Нельзя бесконечно прыгать в воздухе.

6. **Коллизии**

   - Игрок не проходит через стены и препятствия.
   - Поведение устойчиво при движении по диагонали.

7. **Камера и FOV**

   - Настроить разумный FOV.
   - Камера остаётся привязана к игроку.
   - Не добавлять сложный head bob или camera shake.

8. **Debug-информация**

   - Добавить небольшой debug overlay: позиция игрока, yaw, pitch.
   - Он должен помогать изучению координат и трансформаций.

9. **Тестирование**

   - Unit-тестировать только чистую математику: clamp pitch, нормализацию направления, расчёт horizontal forward/right.
   - Physics/rendering проверять ручным запуском.

10. **Завершение**

   - README должен объяснить `Vector3`, мировые оси, local/world coordinates, transform, yaw/pitch, perspective camera, FOV, gravity и collider.
   - Выполнить полный набор Cargo-проверок.

## Результат первой версии

Минимальная 3D-комната, в которой игрок может ходить от первого лица, смотреть мышью, прыгать, падать под действием гравитации и сталкиваться со стенами и препятствиями.

Проверка: `cargo run`; пройти по комнате; упереться во все стены; обойти препятствие; прыгнуть; проверить mouse look и debug-информацию; выполнить все Cargo-проверки.

## Не входит в первую версию

- Оружие.
- Стрельба.
- Враги.
- AI.
- Двери.
- Предметы.
- Анимация рук.
- Сложное освещение.
- Постобработка.
- Сохранения.
- Меню.
- Полноценный уровень.

- Crouch.

- Настройки чувствительности мыши.
