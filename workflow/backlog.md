# Открытый backlog

В этом файле находятся только неначатые работы: scope, приоритет, зависимости, порядок и ожидаемая
проверка. Текущий статус и результаты выполнения записываются только в `workflow/progress.md`.

## Очередь

Берите первую позицию, зависимости которой выполнены. Проверяйте зависимости в репозитории, а не
доверяйте таблице без проверки.

| Position | IDs | Scope | Depends on | Gate |
|---|---|---|---|---|
`Gate` — это дополнительная проверка, которой нет в обычном `make check`. О специальном gate нужно
сообщить при начале задачи и запускать его только после обычной проверки. Если требуется решение
владельца, агент ждёт его и записывает ответ.

## Правила очереди

- Каждая открытая задача есть в упорядоченной очереди.
- У каждого ID очереди есть подробное описание, если только позиция специально не объединяет несколько ID.
- Завершённые записи удаляются после закрытия задачи.
- Заблокированные задачи и решения владельца не маскируются под готовую работу.
